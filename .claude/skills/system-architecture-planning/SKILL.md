# 📖 Skill: System Architecture Planning

## Overview
Provides a framework for planning high-level architecture across WordPress block themes, organizing files cleanly, mapping asset dependencies, and structuring data flow.

## When to Use
Use before creating new major components, refactoring legacy template structures, or designing theme extensions.

## Instructions
1. Map frontend requirements to WordPress block theme artifacts (templates, template parts, block patterns).
2. Establish CSS custom variable tokens and global utility boundaries.
3. Plan JS script dependencies and localization parameters.
