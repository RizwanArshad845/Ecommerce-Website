# 📖 Skill: CSS Responsive Design & Keyframe Animations

## Overview
Blueprint skill for modern responsive layouts, variable systems, glassmorphism components, and butter-smooth CSS keyframe micro-animations.

## When to Use
Use when styling UI components, writing responsive layouts, applying CSS variables, adding hover/glow effects, or creating keyframe animations.

## Instructions
1. Define tokens in `:root` (`--primary-gold`, `--surface-glass`, etc.).
2. Apply `backdrop-filter: blur()` and subtle borders for glassmorphism.
3. Use mobile-first media queries (`@media (min-width: 768px)`).
