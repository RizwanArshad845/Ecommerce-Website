# 📖 Skill: Full-Stack Integration (CSS, HTML, JS & PHP)

## Overview
Guides subagents through orchestrating end-to-end features where PHP backend logic, HTML5 structure, CSS styling, and JS interactivity converge seamlessly.

## When to Use
Use when building a complete component or section from scratch across all web technologies (PHP -> HTML -> CSS -> JS).

## Instructions
1. Render backend data securely in PHP.
2. Structure semantic markup in HTML with data attributes.
3. Apply responsive styling and glassmorphism in CSS.
4. Attach JS listeners to data attributes for interactive feedback.
