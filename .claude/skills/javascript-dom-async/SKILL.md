# 📖 Skill: JavaScript DOM Manipulation & Async Execution

## Overview
Standard patterns for writing high-performance Vanilla JavaScript, event handling, AJAX requests, dynamic loading, and DOM state updates in WordPress themes.

## When to Use
Use when adding frontend interactivity, script initialization, dynamic scroll/click listeners, or AJAX requests.

## Instructions
1. Guard execution with `DOMContentLoaded`.
2. Use event delegation for dynamic elements (`event.target.closest(...)`).
3. Leverage modern async/await for Fetch calls.
