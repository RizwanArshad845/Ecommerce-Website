# 📖 Skill: Clean Code Implementation

## Overview
Standards for authoring clean, fully realized, production-ready code with maximum maintainability and zero placeholder logic.

## When to Use
Use when implementing any feature, writing new components, or updating existing source code files.

## Instructions
1. Avoid placeholder comments like `// TODO: add logic later`. Write fully functional code.
2. Use descriptive variable and function names following language conventions.
3. Keep functions focused on a single responsibility.
