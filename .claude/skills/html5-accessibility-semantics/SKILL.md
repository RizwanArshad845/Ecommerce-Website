# 📖 Skill: HTML5 Accessibility, Semantics & Block Structure

## Overview
Guidelines for authoring W3C-compliant, semantic, screen-reader accessible HTML5 structures and WordPress block template markup.

## When to Use
Use when modifying or creating HTML templates (`templates/*.html`), block parts (`parts/*.html`), or structural HTML containers.

## Instructions
1. Use semantic HTML tags (`<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`).
2. Include ARIA attributes (`aria-expanded`, `aria-label`, `role`).
3. Ensure single `<h1>` per page.
